# Full-page ECG examples

Four full-page ECG images are retained here for image exploration. The companion `testing_and_development.ipynb` reads this directory for intensity analysis and threshold inspection.

For the self-contained reconstruction walkthrough, start with `signal_fixing.ipynb`, which uses the prepared binary crop in `result/example.png`.

See [data notes](../docs/DATA.md) for dataset context and the distinction between page images and the reconstruction input.
