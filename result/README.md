# Original experiment images

This directory preserves the project's original crops and historical results.

- `example.png`: prepared binary ECG crop used by the current reproducible demo; white foreground on black, 862 × 392 pixels.
- `example1.png`: another crop retained for exploration.
- Other PNG files: historical reconstruction and debugging outputs.

New notebook runs write to `outputs/signal-fixing/`. Verified presentation figures and their metrics are available in [docs/assets/](../docs/assets/).
